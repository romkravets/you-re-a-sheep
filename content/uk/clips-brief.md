# Бриф на кліпи для пілота

Для власника. Усі 8 кліпів готові. 7 — відео з Wikimedia Commons у суспільному надбанні або
під CC0 (джерела — у полі `license` кожного кліпу в `content/uk/episodes/pilot.json`).
Горизонтальні відео поставлені по центру вертикального кадру з розмитою копією згори й знизу,
як репост у TikTok. `p1-ad` — анімована «рекламна» заставка, згенерована кодом без ШІ
(`scripts/make-ad-clip.py`). Будь-який кліп можна замінити своїм **з тим самим id**. Від `p1-cats` залежить правильна
відповідь на питання, тож вимоги до нього обов'язкові, а не побажання.

## Загальні правила для всіх кліпів

- **Тривалість 3–5 с**, вертикально **9:16** (після конвертації 720×1280).
- **Жодного тексту у відео.** Плашки («ТЕРМІНОВО‼️…», «ВЧЕНІ В ШОЦІ…»), підписи, нік, лайки
  й кнопки малює сторінка поверх відео. Не вшивай у кадр субтитри, водяні знаки чи плашки.
- **Без брендів і логотипів** (упаковки, вивіски, одяг з написами, номери авто).
- **Без людей, яких можна впізнати**: ні облич крупним планом, ні дітей. Руки, силуети, люди здалеку
  і спиною до камери — можна.
- Ніякого згенерованого ШІ відео чи зображень.
- Ліву частину кадру приблизно від 30 % до 60 % висоти в кліпах з плашкою закриває текст;
  праворуч знизу — кнопки, знизу — підпис. Головне в кадрі тримай по центру.
- Звук не обов'язковий: стрічка стартує без звуку.

## Що має бути в кожному кліпі

| id | Що показує відео | Обов'язково |
|---|---|---|
| `p1-cats` | Дорослий кіт і два кошенята біля миски. | **Рівно 3 коти, усіх добре видно весь час.** Ні четвертого кота, ні кота, що на мить заходить у кадр чи видно лише хвіст. Від цього залежить відповідь «Три» на питання «Скільки котів було у відео з мискою?». Якщо заміниш кліп і котів буде інша кількість, зміни варіанти й `correct` у питанні `pilot-cats`. |
| `p1-fake` | Нейтральне тло під фейкову «новину» про вимкнення месенджерів: екран телефону здалеку, розмитий, місто ввечері. | Жодних справжніх медіа, логотипів месенджерів чи впізнаваних людей. Текст фейку малює сторінка. |
| `p1-dog` | Мама-вовчиця з вовченям (зараз), або будь-яка тварина. | Без людей у кадрі. Підпис кліпу описує, що на відео: зміниш відео — зміни й `caption`. |
| `p1-clickbait` | Хтось їсть морозиво (зараз — пес вилизує собаче морозиво з миски). | Ніяких брендів на упаковці. Плашку про «9 хом'яків» малює сторінка. |
| `p1-rage` | Калюжа під дощем (зараз), або авто, що їде крізь калюжу. | Номер не читається, водія не видно, дітей у кадрі немає. Історію про «облив дітей» розповідає плашка, а не відео. |
| `p1-rink` | Ковзанка взимку: ковзани на льоду, люди здалеку. | Без вивісок і назв парку. Дату на плашці малює сторінка (її потім «переписують» у питанні). |
| `p1-ad` | Анімована заставка «реклами сироватки»: рожевий градієнт, піпетка, крапля, кола, боке. Можна замінити справжнім відео: руки з кремом, баночка без етикетки. | **Без облич.** Кліп подає людину як «дерматолога»-шахрая, а стокові ліцензії забороняють показувати впізнаваних людей у поганому світлі. Без брендових баночок. |
| `p1-real` | Восьминіг під водою. | Справжнє відео восьминога, без тексту в кадрі. |

## Куди класти файли

Для кожного id потрібні три файли з тим самим іменем:

```
public/clips/<id>.webm   VP9
public/clips/<id>.mp4    H.264
public/clips/<id>.jpg    перший кадр (постер)
```

Наприклад: `public/clips/p1-cats.webm`, `public/clips/p1-cats.mp4`, `public/clips/p1-cats.jpg`.

## Як конвертувати (ffmpeg)

Ті самі параметри, що й у `scripts/make-placeholder-clips.sh`. Підстав свій файл, id і,
якщо треба, секунду початку (`-ss`):

```sh
id=p1-cats; src=~/Downloads/cats.mov; start=0
vf="scale=720:1280:force_original_aspect_ratio=increase,crop=720:1280,fps=25,format=yuv420p"

ffmpeg -y -ss "$start" -i "$src" -t 5 -vf "$vf" -an \
  -c:v libvpx-vp9 -crf 40 -b:v 0 -row-mt 1 "public/clips/$id.webm"
ffmpeg -y -ss "$start" -i "$src" -t 5 -vf "$vf" -an \
  -c:v libx264 -crf 30 -preset slow -movflags +faststart "public/clips/$id.mp4"
ffmpeg -y -i "public/clips/$id.mp4" -frames:v 1 -q:v 5 "public/clips/$id.jpg"
```

`-t 5` обрізає до 5 с (можна 3–4). `-an` прибирає звук; якщо звук потрібен, заміни `-an` на
`-c:a libopus -b:a 64k` для webm і `-c:a aac -b:a 96k` для mp4.

Для **горизонтального** відео замість обрізання краще поставити його по центру з розмитою копією
згори й знизу (так зроблено з кліпами з Commons). Заміни `vf` на:

```sh
vf="split[a][b];[a]scale=720:1280:force_original_aspect_ratio=increase,crop=720:1280,boxblur=24:2,eq=brightness=-0.1[bg];[b]scale=720:-2[fg];[bg][fg]overlay=(W-w)/2:(H-h)/2,fps=25,format=yuv420p"
```

і передай його через `-filter_complex "$vf"` замість `-vf "$vf"`.

## Ліцензія

Після заміни онови запис `license` цього кліпу в `content/uk/episodes/pilot.json`:
`source` (автор або «власне»), `url` (сторінка відео на Pexels чи інше джерело),
`license` (наприклад, `Pexels License`). Поки хоч один кліп має `placeholder`,
перевірка релізу не пройде.
